AWS Serverless Architecture

How I Built a Serverless Cloud Archiving App on AWS

✍️ Julien Mveng (AWS Certified Solutions Architect) 📅 January 2026 ⏱️ 5 min read

Introduction & Core Challenge

In modern digital enterprises, retaining terabytes of business records, invoices, and sensitive documents securely while keeping cloud storage bills low is a critical engineering challenge. Storing everything on expensive high-availability tiers creates unnecessary FinOps waste, while traditional cold-storage setups often suffer from clumsy retrieval processes.

I designed and deployed a serverless, zero-maintenance archiving solution on AWS that empowers employees to securely upload, encrypt, and retrieve documents seamlessly with automated Glacier lifecycle transitions.

High-Level System Architecture

Client (React / Web App)
      │  
      ├──▶ [1] Cognito User Pool (JWT Auth & Scoped IAM Roles)
      │
      ├──▶ [2] API Gateway (REST Endpoints & Rate Limiting)
      │          │
      │          ▼
      │     [3] AWS Lambda (Token Validation & S3 Pre-Signed URLs)
      │
      └──▶ [4] Amazon S3 Bucket (Direct Multi-Part Upload)
                 │
                 ├──▶ SSE-KMS Customer-Managed Encryption
                 └──▶ Lifecycle Policy: S3 Standard ➔ Glacier Deep Archive

1. Authentication & Scoped Isolation with Amazon Cognito

Security starts with zero trust. A Cognito User Pool handles authentication and MFA. Upon login, an authenticated IAM role is assumed with strict tenant scoping. Users are strictly constrained to their personal folder path: 

// Example S3 Resource Scope in IAM Policy
"Resource": "arn:aws:s3:::cloudly-secure-archive/${cognito-identity.amazonaws.com:sub}/*"

2. Direct-to-S3 Uploads via Pre-Signed URLs

Instead of passing multi-megabyte payloads through API Gateway and Lambda (which would incur payload limits and high execution costs), the browser requests a cryptographically signed upload URL from Lambda. Lambda validates permissions and issues a pre-signed URL with a 5-minute TTL. The browser then streams the file directly to S3.

3. Automated Tiering & Cost Optimization

By configuring automated S3 Lifecycle Rules, documents are moved to S3 Infrequent Access (IA) after 30 days and archived to Glacier Deep Archive after 90 days, cutting recurring storage costs by up to 80%.

Key Takeaways & Best Practices

  • Never expose AWS credentials in the frontend: Always generate short-lived pre-signed URLs.
  • Enforce KMS Encryption: Enable default bucket encryption using customer-managed KMS keys with key rotation.
  • Automate Archival Rules: FinOps lifecycle rules ensure you never pay primary storage rates for dormant archives.
