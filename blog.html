How I Built a Serverless Cloud Archiving App on AWS

Julien Mveng (AWS Certified Solutions Architect) January 2026 5 min read

Introduction & Core Challenge

In modern digital enterprises, retaining terabytes of business records, invoices, and sensitive documents securely while keeping cloud storage bills low is a critical engineering challenge. Storing everything on expensive high-availability tiers creates unnecessary FinOps waste, while traditional cold-storage setups often suffer from clumsy retrieval processes.

I designed and deployed a serverless, zero-maintenance archiving solution on AWS that empowers employees to securely upload, encrypt, and retrieve documents seamlessly with automated Glacier lifecycle transitions.

High-Level System Architecture

Client (React / Web App)
    │  
    ├──▶ [1] Cognito User Pool (JWT Auth & Scoped IAM Roles)
    │
    ├──▶ [2] API Gateway (REST Endpoints & Rate Limiting)
    │          │
    │          ▼
    │     [3] AWS Lambda (Token Validation & S3 Pre-Signed URLs)
    │
    └──▶ [4] Amazon S3 Bucket (Direct Multi-Part Upload)
               │
               ├──▶ SSE-KMS Customer-Managed Encryption
               └──▶ Lifecycle Policy: S3 Standard → Glacier Deep Archive

1. Authentication & Scoped Isolation with Amazon Cognito

Security starts with zero trust. A Cognito User Pool handles authentication and MFA. Upon login, an authenticated IAM role is assumed with strict tenant scoping. Users are strictly constrained to their personal folder path: 

// Example S3 Resource Scope in IAM Policy
"Resource": "arn:aws:s3:::cloudly-secure-archive/${cognito-identity.amazonaws.com:sub}/*"

2. Direct-to-S3 Uploads via Pre-Signed URLs

Instead of passing multi-megabyte payloads through API Gateway and Lambda (which would incur payload limits and high execution costs), the browser requests a cryptographically signed upload URL from Lambda. Lambda validates permissions and issues a pre-signed URL with a 5-minute TTL. The browser then streams the file directly to S3.

3. Automated Tiering & Cost Optimization

By configuring automated S3 Lifecycle Rules, documents are moved to S3 Infrequent Access (IA) after 30 days and archived to Glacier Deep Archive after 90 days, cutting recurring storage costs by up to 80%.

Key Takeaways & Best Practices

  • Never expose AWS credentials in the frontend: Always generate short-lived pre-signed URLs.
  • Enforce KMS Encryption: Enable default bucket encryption using customer-managed KMS keys with key rotation.
  • Automate Archival Rules: FinOps lifecycle rules ensure you never pay primary storage rates for dormant archives.

Cloud Security & Compliance

Security Best Practices for Startups on AWS

Julien Mveng (AWS Certified Solutions Architect) February 2026 4 min read

1. Establish Granular IAM Governance Early

The number one cause of cloud data breaches is compromised overly-permissive IAM credentials. Never use the AWS root account for daily operations. Implement single sign-on (IAM Identity Center) with mandatory hardware MFA and assign granular permission boundaries.

2. Encrypt Everything by Default

Enforce S3 bucket default encryption with AWS KMS customer-managed keys (CMK), enable TLS 1.3 on all API Gateway and CloudFront distributions, and enforce EBS volume encryption on creation.

3. Centralize Logging & Threat Detection

Turn on AWS CloudTrail across all AWS regions, ship logs to an isolated, write-once security account, and activate Amazon GuardDuty for automated anomaly detection. 

# Quick Terraform Snippet: Enforce S3 Bucket Encryption
resource "aws_s3_bucket_server_side_encryption_configuration" "secure_bucket" {
  bucket = aws_s3_bucket.main.id

  rule {
    apply_server_side_encryption_by_default {
      kms_master_key_id = aws_kms_key.cloudly_key.arn
      sse_algorithm     = "aws:kms"
    }
  }
}

4. Continuous Disaster Recovery Drills

Having automated backups is only half the battle. Schedule quarterly automated cross-region restore tests to verify Recovery Point Objective (RPO) and Recovery Time Objective (RTO) targets.

Cloud Migration & Modernization

Zero-Downtime AWS Migration: From Monolith to Serverless

Julien Mveng (AWS Certified Solutions Architect) March 2026 6 min read

Strategic Migration Framework

Migrating mission-critical production workloads to AWS requires a proven, risk-mitigated strategy. Rather than risky big-bang cuts, we apply the Strangler Fig pattern to migrate services incrementally.

1. Database Synchronization with AWS DMS

Using AWS Database Migration Service (DMS) with Change Data Capture (CDC), data is continuously replicated from source databases (PostgreSQL/MySQL) to Amazon Aurora Serverless in real time, keeping lag under 1 second.

2. Containerized Workloads on ECS Fargate

Legacy monoliths are containerized into lightweight Docker images and deployed on Amazon ECS with AWS Fargate, eliminating server patching and providing auto-scaling behind Application Load Balancers.

3. Route 53 Weighted DNS Cutover

Traffic is transitioned gradually (10% → 50% → 100%) using Amazon Route 53 weighted routing policies. If anomalies arise, rollback is instant with zero data loss.

FinOps & Cost Optimization

FinOps & AWS Cost Optimization: Cutting Cloud Bills by 40%

Julien Mveng (AWS Certified Solutions Architect) April 2026 5 min read

The 4 Pillars of Cloud Cost Optimization

Many organizations overspend on AWS by 30% to 50% due to unattached EBS volumes, oversized EC2 instances, and unoptimized storage tiers.

1. Right-Sizing & Graviton3 Adoption

Migrating EC2, ECS, and Lambda runtimes from x86 to ARM-based AWS Graviton3 delivers up to 25% better compute performance at 20% lower cost.

2. S3 Intelligent-Tiering

Enabling S3 Intelligent-Tiering automatically moves objects between frequent, infrequent, and archive access tiers without retrieval fees or operational overhead.

3. Automated Idle Resource Shutdown

Using EventBridge Scheduler and Lambda to turn off non-production development environments outside business hours immediately cuts non-prod compute costs by 65%.
